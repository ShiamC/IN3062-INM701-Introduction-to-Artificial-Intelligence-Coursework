# IN3062-INM701-Introduction-to-Artificial-Intelligence-Coursework
Repository of all of the coursework in Introduction to AI
Project overview

The aim of this project is to identify students at risk of dropping out of higher education early enough for support where support would be offered. By using data available at enrolment and at the end of the first year, we will predict whether each student will graduate, drop out or remain enrolled. This is a three-class classification problem.

We will compare at least two of the models taught in the module and then we will evaluate them against majority-class and simple-model baselines.
